# SSPM - Simple Secure Password Manager

Simple Secure Password Manager - это настольное приложение для безопасного хранения и управления паролями. Приложение написано на языке Python с использованием библиотек tkinter и cryptography и распространяется в виде exe файла с открытым исходным кодом.

Приложение ориентировано на пользователей, которым важно хранить учетные данные локально и в зашифрованном виде без передачи данных в интернет.

## Основные возможности

- Защита приложения мастер-паролем  
- Шифрование всех данных с использованием библиотеки cryptography  
- Хранение паролей с полями: название, логин, пароль и тег  
- Генерация случайных надежных паролей с возможностью мгновенного копирования  
- Просмотр всех сохраненных паролей в одном списке  
- Копирование пароля двойным нажатием  
- Добавление паролей в избранное  
- Поиск паролей по названию и фильтрация по тегам  
- Логи входа в приложение с датой, временем и результатом попытки  
- Светлая и темная темы интерфейса  
- Сворачивание приложения в трей  
- Быстрый доступ к избранным паролям через меню трея  

## Формат распространения

- Приложение доступно в виде exe файла и не требует установленного Python  
- Исходный код проекта открыт и доступен для изучения  
- Файл requirements.txt присутствует в репозитории и используется только для разработки и сборки  

## Используемые технологии

- Python  
- tkinter - графический интерфейс  
- cryptography - шифрование данных  

## Использование exe версии

1. Скачайте ZIP-архив в разделе Releases
2. Запустите файл SSPM.exe - установка не требуется. Перед запуском достаньте всё из архива.
3. При первом запуске создайте мастер-пароль  
4. После ввода мастер-пароля создастся файл passwords.db. Он хранит в себе все пароли, доступ к которым зашифрован вашим мастер-паролем.

## Разработка и запуск из исходного кода

Для разработки и запуска из исходного кода необходим установленный Python с зависимостями (файл requirements.txt)

## Безопасность

Все пароли хранятся локально и зашифрованы. Ключ шифрования формируется на основе мастер-пароля пользователя. Данные не отправляются в сеть.

## Логи

Приложение сохраняет журнал входов, в котором фиксируется:
- дата и время входа  
- успешность или неуспешность авторизации
